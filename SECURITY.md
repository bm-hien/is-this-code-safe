# Security policy

ITCS parses potentially hostile source. Please read
[docs/THREAT_MODEL.md](docs/THREAT_MODEL.md) before handling real samples.

When this repository is hosted on GitHub, report scanner escape, unsafe file
handling, checkpoint loading, or denial-of-service issues through a private
security advisory. Otherwise contact the repository owner through a private
channel.

Do not open a public issue containing live malware, exploit payloads,
credentials, private source, or a reproducer that executes during testing.
Provide an inert minimal source string and affected version when possible.
